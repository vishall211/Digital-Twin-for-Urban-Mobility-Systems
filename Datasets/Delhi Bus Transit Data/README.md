# Delhi Bus Transit Dataset

> [!NOTE]
> This dataset is generated by running the real-time data script against the **Delhi OTD GTFS-RT API**.
> Each CSV snapshot captures the live position of every active DTC bus at the moment the script runs.
> New files accumulate over time — one CSV per run.

---

## 📦 Storage & Access

| Detail | Info |
|--------|------|
| **Stored locally** | `Datasets/Delhi Bus Transit Data/` |
| **Gitignored** | ✅ Yes — CSV snapshots are excluded from version control (re-generated on each run) |
| **Data source** | [Delhi Open Transit Data (OTD) — GTFS-RT API](https://otd.delhi.gov.in) |
| **Feed type** | GTFS Realtime — `VehiclePositions.pb` |
| **API endpoint** | `https://otd.delhi.gov.in/api/realtime/VehiclePositions.pb?key=<API_KEY>` |

## 🏛️ Schema

| Column | Type | Description |
|--------|------|-------------|
| `entity_id` | string | Unique entity ID from the GTFS-RT feed (matches vehicle registration) |
| `trip_trip_id` | string | Trip ID from the GTFS schedule (format: `<route>_<direction>_<start_min>`) |
| `trip_start_time` | string | Scheduled trip start time (HH:MM:SS) |
| `trip_start_date` | int | Trip start date (YYYYMMDD) |
| `trip_schedule_relationship` | int | `0` = SCHEDULED, `1` = ADDED (unplanned trip) |
| `trip_route_id` | int | Route ID from GTFS static feed |
| `position_latitude` | float | Current latitude of the bus (WGS84) |
| `position_longitude` | float | Current longitude of the bus (WGS84) |
| `position_speed` | float | Current speed in **metres per second** |
| `timestamp` | int | Unix epoch timestamp of the GPS fix (UTC) |
| `vehicle_id` | string | Vehicle registration number (e.g. `DL51EV9674`) |
| `vehicle_label` | string | Human-readable vehicle label (same as `vehicle_id` for DTC buses) |

## ⚙️ How to Collect a New Snapshot

Run the data script from the project root:

```bash
.venv/bin/python3 "Code/Dataset – Delhi Bus Data_RealTime.py"
```

This will:
1. Hit the Delhi OTD GTFS-RT API
2. Parse the protobuf `VehiclePositions.pb` feed
3. Flatten nested fields (trip, position, vehicle) into a flat CSV
4. Save a timestamped CSV into this folder

> [!IMPORTANT]
> The API key is currently **hardcoded** in the script. Move it to a `.env` file before sharing or committing the script publicly:
> ```
> DELHI_OTD_API_KEY=your_key_here
> ```
